# StudyTracker

StudyTracker is a learning project built with C# and ASP.NET Core.

The goal of this project is to practice backend architecture, separation of responsibilities, REST API fundamentals, HTTP responses, dependency injection, and project documentation.

This is not a production-ready system yet. It is a backend learning project created to understand how a real application is structured.

## Project Status

This project is currently in development.

Current focus:

- Consolidating backend architecture
- Practicing REST API fundamentals
- Improving service results and HTTP responses
- Documenting the API with OpenAPI and Scalar UI
- Preparing the project for future database persistence
